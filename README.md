# KanfiAutomator

劇団 **Theatre MERCURY** の伝統企画「感フィ」のスライドを自動生成する [Google Apps Script](https://developers.google.com/apps-script)（GAS）です。Google フォームで集めたメンバーへのメッセージから、メンバーごとの感フィスライドを Google スライド上に自動で組み立てます。

## できること

- **フォーム回答の取り込み** — 感フィ回答スプレッドシートから、メンバー名・呼んでほしい名前・各メンバーへのメッセージを取得
- **スライド自動生成** — メンバー1人につき2枚のスライドを生成し、メッセージを差し込み
- **再実行に強い設計（冪等性）** — スピーカーノートに識別子を埋め込み、既存スライドを検出。再実行しても二重生成・初期化が起きないように制御
- **実行ログ** — 進捗とエラーをスプレッドシートのセル（`D12`）にリアルタイム表示
- **配色の自動化** — HSL でヒューをランダムに選び、スライドの色味を自動決定

## 使い方

1. 感フィ管理用スプレッドシートにバインドされた GAS プロジェクトへ、`ver2.3.js` の内容を配置します。
2. 管理用スプレッドシートの「メイン」シートに、入力値を設定します。
   - `B3`: 感フィ回答スプレッドシートの URL
   - 出力先スライドの URL（「メイン」シートの所定セル）
3. `main()` を実行すると、回答が読み込まれ、メンバーごとのスライドが生成されます。
4. 実行中の進捗・エラーは「メイン」シートの `D12` セルに表示されます。

## バージョン

- 最新: `ver2.3.js`
- 旧版: `Legacy/`（ver1 〜 ver2.2）に保存
